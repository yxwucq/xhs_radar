红薯雷达 隐私政策

最后更新：2026 年 3 月 26 日

概述

红薯雷达（以下简称"本扩展"）是一款浏览器扩展，用于在小红书网页端识别并过滤低质量内容。我们重视用户隐私，本政策说明本扩展如何处理数据。

数据收集与使用

本扩展不收集、不存储、不传输任何用户个人信息。

本扩展在运行过程中会处理以下数据：

  • 笔记标题、作者名、点赞数 — 从小红书页面 DOM 中读取，用于内容质量分析。这些数据仅在本地处理或发送至用户自行配置的 AI API 端点。
  • API 配置信息（API Key、API 地址、模型名称）— 由用户手动输入，存储在浏览器本地 chrome.storage.local 中，不会上传至任何第三方服务器。
  • 分析结果缓存 — 存储在浏览器本地，用于避免重复分析。

第三方服务

本扩展会将笔记标题等公开信息发送至用户自行配置的 AI API 端点（如 OpenAI、Anthropic 或其他兼容服务）进行内容分析。本扩展不控制这些第三方服务的数据处理方式，请参阅相应服务的隐私政策。

如果用户未配置 API Key，本扩展不会向任何外部服务发送数据。

数据存储

所有数据均存储在用户浏览器本地（chrome.storage.local），包括：

  • 用户配置（API 设置、过滤规则、灵敏度等）
  • 分析结果缓存

用户可随时通过扩展设置页面清除缓存，或卸载扩展以删除所有本地数据。

权限说明

  • storage — 用于在浏览器本地保存配置和缓存
  • activeTab — 用于读取当前小红书页面内容
  • xiaohongshu.com — 用于在小红书页面注入内容分析脚本
  • 可选的主机权限 — 用于访问用户配置的 API 端点，仅在用户明确授权后生效

变更通知

如本隐私政策发生变更，我们将在此页面更新内容并修改"最后更新"日期。

联系方式

如有隐私相关问题，请通过 GitHub 仓库提交 Issue。

红薯雷达 Privacy Policy

Last updated: March 26, 2026

Overview

红薯雷达 ("the Extension") is a browser extension that identifies and filters low-quality content on the Xiaohongshu (Little Red Book) website. We value user privacy, and this policy explains how the Extension handles data.

Data Collection and Use

The Extension does not collect, store, or transmit any personal user information.

The Extension processes the following data during operation:

  • Note titles, author names, and like counts — Read from the Xiaohongshu page DOM for content quality analysis. This data is processed locally or sent to an AI API endpoint configured by the user.
  • API configuration (API Key, base URL, model name) — Manually entered by the user and stored in the browser's local chrome.storage.local. This data is never uploaded to any third-party server.
  • Analysis result cache — Stored locally in the browser to avoid redundant analysis.

Third-Party Services

The Extension sends publicly visible note titles to an AI API endpoint configured by the user (such as OpenAI, Anthropic, or other compatible services) for content analysis. The Extension does not control how these third-party services handle data; please refer to their respective privacy policies.

If no API Key is configured, the Extension does not send data to any external service.

Data Storage

All data is stored locally in the user's browser (chrome.storage.local), including:

  • User configuration (API settings, filter rules, sensitivity, etc.)
  • Analysis result cache

Users can clear the cache at any time via the Extension's settings page, or uninstall the Extension to remove all local data.

Permissions

  • storage — Save configuration and cache locally in the browser
  • activeTab — Read the current Xiaohongshu page content
  • xiaohongshu.com — Inject content analysis scripts on Xiaohongshu pages
  • Optional host permissions — Access user-configured API endpoints, only active after explicit user authorization

Changes

If this privacy policy is updated, we will revise the content on this page and update the "Last updated" date.

Contact

For privacy-related questions, please submit an Issue on the GitHub repository.
